## 6. Befunde

### K1 – KRITISCH: Bild s08 (DE und SQ), ca. 102,3–103,6 s

**Jetzt:** Die Absperrung erscheint offen und grau, während das grüne Badge „Dieser Weg bleibt frei.“ noch steht. Erst beim Zudrehen wird sie rot und bekommt das X. Die Botschaft lautet damit „nur geschlossen ist falsch“.

**Richtig:** Die Absperrung ist ab dem ersten Bild als Fehler markiert, ohne Schließ-Animation. Das grüne Badge ist vorher verschwunden. Nötige Änderungen im Szenencode:

**1. `src/circuit.js`, Funktion `valve()`** – Parameter `err` ergänzen, damit ein offenes Ventil rot gezeichnet werden kann:

```js
function valve(ctx, x, y, { closed = 0, a = 1, dir = 'v', s = 1, err = 0 } = {}) {
  …
  const red = closed > 0.5 || err > 0.5;
  const col = red ? C.err : C.ink2;
  … ctx.fillStyle = red ? C.err : '#fff'; …
```

Der Rest bleibt gleich. Der Griff zeigt weiter „offen“. Andere Aufrufe sind nicht betroffen, weil `err` standardmäßig 0 ist.

**2. `src/system8.js`, Zeile 144** – `err` an `valve()` weitergeben:

```js
CI.valve(ctx, BADV[0], BADV[1], { closed: bad.closed || 0, err: bad.err || 0, a: bad.a, dir: 'v', s: 1.2 });
```

**3. `src/scenesA.js`, `D.s08.draw` (Zeilen 341–347)** – Neue Fassung:

```js
const pg = prog(t, c.path, c.path + 0.8), bv = prog(t, c.bad, c.bad + 0.5);
S8.drawSys(ctx, { …, pathGlow: pg, pathErr: bv > 0.3,
  badValve: { a: bv, closed: 0, err: 1 }, hi: { … } });
bigBadge(ctx, 'big08', S, 760, 960, prog(t, c.path + 0.6, c.path + 1.2) * (1 - prog(t, c.bad - 0.4, c.bad)), C.ok);
CI.xMark(ctx, bx - 75, by - 70, 40, prog(t, c.bad + 0.4, c.bad + 0.8));   // nicht mehr auf dem Trichter
chipL(ctx, 'closed', S, bx - 230, by + 10, { a: prog(t, c.bad + 0.3, c.bad + 0.8), px: 24, color: C.err });
```

Was sich damit ändert:
- `cl` (Schließen) entfällt ganz.
- Das Badge ist weg, bevor der Hahn kommt (`c.bad − 0,4` bis `c.bad`).
- Der Weg wird rot, sobald der Hahn erscheint (`c.bad + 0,15`).
- X und Etikett folgen 0,3–0,8 s nach `c.bad`.

**Neu rendern:** Nur Szene s08, DE und SQ. Ton und Timeline bleiben unverändert.

**Danach prüfen:** Standbilder bei 102,6 / 103,0 / 104,0 s. Zu sehen sein müssen ein roter, offener Hahn, kein grünes Badge, das X frei neben dem Hahn und das Etikett nicht verdeckt.

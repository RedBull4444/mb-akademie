## 6. Befunde

### K1 – MITTEL: Bild s08, DE und SQ, ca. 103,5–104,7 s

**Jetzt:** Die Absperrung erscheint offen und grau im grünen Weg. Erst beim Zudrehen wird sie rot und bekommt das X. Das X selbst liegt auf der Sicherheitsgruppe. Botschaft: „nur geschlossen ist falsch“.

**Richtig:** Die Absperrung ist vom ersten Bild an als Fehler markiert, ohne Schließ-Animation, und das X steht an der Absperrung.

Änderungen im Szenencode:

**1. `src/circuit.js`, Funktion `valve()`:** Parameter `err = 0` ergänzen:

```js
const red = closed > 0.5 || err > 0.5;
const col = red ? C.err : C.ink2;
ctx.fillStyle = red ? C.err : '#fff';
```

Diese Änderung ist identisch mit M08 K1.

**2. `src/system9.js`, Zeile 179:**

```js
CI.valve(ctx, (GEN.x + GEN.w + X.sg) / 2 + 8, Y.VL, { closed: bad.closed || 0, err: bad.err || 0, a: bad.a, dir: 'h', s: 1.2 });
```

**3. `src/scenesA.js`, `D.s08.draw`, Zeilen 299–306:**

```js
const z = prog(t, 0, 0.8, E.io), tr = posLerp(TR7, TR8, z);
const ba = prog(t, c.bad, c.bad + 0.4);
S9.drawSys(ctx, { …, pathGlow: vis(t, 0.6, S.dur + 1, 0.4, 0.2), pathErr: ba > 0.3 ? 1 : 0,
  badValve: { a: ba, closed: 0, err: 1 } });
chipL(ctx, 'path_ok', S, 960, 900, { a: prog(t, 1.0, 1.5) * (1 - prog(t, c.bad - 0.3, c.bad)), px: 28, bg: C.ok });
const [bx, by] = Q(tr, (S9.GEN.x + S9.GEN.w + S9.X.sg) / 2 + 8, S9.Y.VL);
CI.xMark(ctx, bx, by + 75, 34, prog(t, c.bad + 0.4, c.bad + 0.8));      // unter der Absperrung, nicht auf der Sicherheitsgruppe
```

Dabei entfällt `cl` (das Schließen). Der grüne Chip ist weg, bevor der Hahn erscheint. Der Weg wird rot, sobald der Hahn sichtbar ist.
